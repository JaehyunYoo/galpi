Galpi 0.3.2 — macOS 13 이상 / Intel·Apple Silicon 공용

설치
1. DMG를 열고 Galpi.app을 Applications 폴더로 드래그합니다.
2. 응용 프로그램 폴더에서 Galpi를 엽니다.
3. Control + Option + N으로 메모 창, Control + Option + G로 노치를 열고 접습니다.
4. Control + Option + Space로 빠른 실행창을 엽니다. 단축키는 설정 → 폴더·단축키에서 변경합니다.
5. 노치 가운데 폴더 버튼 위에서 휠이나 트랙패드로 스크롤하면 등록한 모든 폴더를 볼 수 있습니다.
6. 창을 닫아도 메뉴 막대에서 실행됩니다. 완전히 종료하려면 Command + Q를 누릅니다.

설치 파일과 최신 배포 안내: https://github.com/JaehyunYoo/galpi/releases
설정·녹음·회의록 사용법: https://github.com/JaehyunYoo/galpi#readme

이 배포 파일의 상태
파일명에 beta 또는 signed-unnotarized가 있으면 Apple 공증을 받지 않은 테스트 빌드입니다.
macOS에서 실행을 막을 수 있습니다. 직접 신뢰하는 출처에서 받은 파일인지 확인한 다음,
앱 실행을 시도하고 시스템 설정 → 개인정보 보호 및 보안 → 확인 없이 열기로 허용할 수 있습니다.
조직에서 관리하는 Mac은 정책에 따라 실행이 제한될 수 있습니다.
보안 기능 전체를 끌 필요는 없습니다.
파일명이 release인 빌드는 release.sh에서 Developer ID 서명과 Apple 공증을 확인한 결과물입니다.

기능별 지원
• 메모·마크다운·테마·폴더 단축키: macOS 13 이상.
• 대면 녹음: 마이크 권한. 온라인 녹음: 마이크와 화면/시스템 오디오 녹음 권한.
• 로컬 음성 변환: Mac 기종·macOS·언어와 설치된 Apple 인식 데이터에 따라 달라집니다.
  지원하지 않으면 전체 기록 탭에 전사문을 붙여넣어 회의록을 만들 수 있습니다.
• ChatGPT: 설정 → ChatGPT·음성 → Continue with ChatGPT에서 본인 계정으로 연결합니다.
  대상 ChatGPT 플랜과 기능 이용 권한이 필요합니다. 별도 API 키는 입력하지 않습니다.
  회의록 생성 시 메모와 전사문이 OpenAI로 전송됩니다. 음성 파일은 전송하지 않습니다.

데이터
메모와 녹음은 ~/Library/Application Support/Galpi 에 저장됩니다.
설정 → 데이터 → 데이터 폴더 열기로 찾을 수 있습니다. 이 폴더를 백업해 주세요.
배포 파일에는 제작자의 메모·녹음·로그인 정보가 들어 있지 않습니다.

검증 범위
Apple Silicon / macOS 26에서 자동 저장, 테마, 편집, 데이터 복원, 로그인 콜백,
합성 오디오 파일 변환을 자동 테스트합니다. Intel과 macOS 13~15 실기기 검증은 아직 필요합니다.
실제 마이크·온라인 회의의 녹음 품질과 ChatGPT 로그인 완료·회의록 생성은 사용자 환경에서 확인이 필요합니다.

Apple 설치 안내: https://support.apple.com/102445

이전 MyCast에서 업데이트
기존 앱을 종료하고 Galpi.app을 실행합니다. 첫 실행 때 이전 데이터 폴더를 Galpi 폴더로 옮깁니다. 기존 Galpi 폴더가 있으면 덮어쓰지 않습니다. 메모·녹음·계정 연결은 유지합니다.
MyCast와 Galpi를 동시에 실행하지 마세요. 기존 권한·ChatGPT 등록에는 MyCast 이름이 남을 수 있습니다.
