폴더 바로가기

폴더 단축키는 Galpi가 실행 중일 때 동작해요.

선택한 AI에 현재 메모와 전사문을 보내요. 녹음 파일은 보내지 않아요.

ChatGPT 구독 연결

연결한 ChatGPT 플랜의 사용 한도를 공유해요. 회의록 생성 시 전체 기록과 메모가 ChatGPT로 전송돼요.

Claude 연결

이 Mac의 공식 Claude Code를 사용해요. 로그인은 Claude Code에서 진행하며, 갈피는 Claude 비밀번호나 로그인 토큰을 저장하지 않아요.

로그인 창이 열리지 않으면 후 터미널에서 실행하고 연결을 확인하세요.

사용 한도와 추가 요금은 Claude Code에 연결한 계정의 조건을 따라요. 추가 사용 크레딧이 청구될 수 있어요.

음성을 글로 변환

Mac에서 처리해요. 기종·macOS·언어에 따라 지원이 달라요. 처음에는 음성 인식 데이터를 다운로드할 수 있으며, 지원하지 않는 경우 전체 기록에 전사문을 붙여넣을 수 있어요.

기본 테마

메모창과 빠른 실행창에 함께 적용돼요.

시스템 설정을 선택하면 Mac의 라이트·다크 모드를 따라가요.

내 맥에 저장

메모, 녹음, 전체 기록, 이전 회의록을 로컬에 보관해요. 이 폴더를 백업하면 데이터를 함께 보관할 수 있어요.

자동 저장과 복구

메모는 자동 저장되고 직전 저장본도 유지해요. 메모 보관함에서 삭제한 메모를 복원할 수 있어요. 다시 생성하기 전의 회의록은 History 폴더에 남아요.
