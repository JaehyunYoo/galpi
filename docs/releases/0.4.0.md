# Galpi 0.4.0 Beta

메모, 폴더 바로가기, 녹음과 회의록을 노치와 단축키로 꺼내 쓰는 Mac 앱입니다.

## 다운로드와 설치

일반 사용자는 **Galpi-0.4.0-universal-beta.dmg**를 받으세요. 소스 코드나 개발 도구 설치 없이 사용할 수 있습니다.

1. DMG를 열고 **Galpi.app**을 **Applications** 폴더로 드래그합니다.
2. 응용 프로그램 폴더에서 **Galpi**를 실행합니다.
3. `⌃ ⌥ N`으로 메모 창, `⌃ ⌥ G`로 노치, `⌃ ⌥ Space`로 빠른 실행창을 엽니다.

**macOS 13 이상 / Intel·Apple Silicon 공용**입니다. 현재 배포본은 Developer ID 서명 및 Apple 공증을 받지 않은 베타입니다. macOS가 실행을 차단하면 출처를 확인한 뒤 **시스템 설정 → 개인정보 보호 및 보안 → 확인 없이 열기**에서 허용할 수 있습니다. 조직 정책에 따라 실행이 제한될 수 있습니다.

## 이번 변경

- 회의록 생성 AI를 **ChatGPT / Claude** 중 선택
- 공식 Claude Code의 설치 여부·로그인 상태 확인 및 로그인 시작·취소
- Claude Sonnet·Opus 선택과 서비스별 모델 설정 보존
- 기존 ChatGPT 연결은 유지하고 Claude가 필요할 때 전환
- Claude 연결 안내·설정 스크린샷 추가

Claude는 공식 Claude Code를 별도로 설치하고 본인 계정으로 로그인해야 합니다. 갈피가 Claude 구독 토큰을 읽거나 저장하지 않습니다. 계정 조건에 따라 추가 사용 크레딧이나 API 사용량 요금이 적용될 수 있습니다. 설치와 로그인은 **설정 → AI·음성**에서 안내합니다.

## 지원 기능

- 마크다운 메모, 체크리스트와 언어별 코드 색상, 자동 저장
- 라이트·다크·사용자 테마
- 독립 메모 창과 전역 단축키, 폴더 바로가기
- 노치의 최근 메모·폴더·녹음 빠른 작업
- 노치 전용 단축키 설정과 접기 버튼 클릭 영역 개선
- 노치의 모든 폴더를 위아래로 스크롤하고 전체 개수 확인
- 대면·온라인 회의 녹음, 로컬 음성 변환과 ChatGPT·Claude 회의록 생성
- 최신 화면과 스크롤 사용법을 포함한 README

## 사용 전 확인

녹음에는 마이크 권한이 필요하고, 온라인 회의에는 화면·시스템 오디오 관련 권한도 필요합니다. 음성 변환 지원은 기기·macOS·언어에 따라 다릅니다. ChatGPT는 설정에서 본인 계정으로 연결하며 해당 기능을 이용할 수 있는 플랜과 권한이 필요합니다.

Apple Silicon / macOS 26.3.1에서 자동 테스트를 통과했습니다. Intel 및 구형 macOS 실기기 검증은 아직 완료하지 않았습니다.

기존 사용자는 녹음을 저장하고 Galpi를 종료한 뒤 앱을 교체하세요. 메모와 녹음은 `~/Library/Application Support/Galpi/`에 별도로 보관됩니다. 업데이트 후 ChatGPT 로그인 정보의 키체인 접근 확인이 다시 표시될 수 있습니다.
